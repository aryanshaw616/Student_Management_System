# 🎓 Student Management System

A modern web application to manage student records efficiently.  
Built with Spring Boot and MySQL, it offers full CRUD functionality with a polished UI.

---

## ✨ Why This Project?

| Feature                  | Benefit                                 |
|--------------------------|------------------------------------------|
| Full CRUD support        | Add, update, delete student data         |
| Instant search/filtering | Real-time results as you type            |
| Performance indicators   | Visual cues for high/low scores          |
| Form validation          | Prevent invalid data entry               |
| REST API ready           | Backend accessible for integrations      |

## ⚙️ Core Functionality

- 🧾 **Student CRUD**: Manage student name, branch, and performance  
- 🔍 **Live Search**: Filter students instantly  
- 📊 **Color Tags**: Badge styling for branches and scores  
- 📱 **Responsive UI**: Optimized for all screen sizes  

---

## 🧩 Technical Highlights

- **Spring Boot 3.x** – Backend framework  
- **Spring Data JPA + Hibernate** – ORM for DB operations  
- **MySQL** – Persistent storage  
- **Thymeleaf** – Templating engine for UI  
- **Bootstrap 5** – Frontend styling  
- **RESTful APIs** – For external integrations  

---

## 🛠️ Tech Stack

### **Backend**
- Java 17

### **Frontend**
- Thymeleaf
